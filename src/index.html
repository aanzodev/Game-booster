The biggest internet wins

  • Use an Ethernet cable instead of Wi-Fi. This removes most lag spikes.
  • On Wi-Fi: use the 5 GHz network and get closer to the router.
  • Pause downloads, streams and cloud backups on your network while playing.
  • Pick the closest server region in each game (Fortnite: Settings → Game → Matchmaking Region).
  • If your router has QoS / gaming mode, turn it on and prioritize your PC.
